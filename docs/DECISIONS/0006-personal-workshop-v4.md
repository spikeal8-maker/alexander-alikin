# ADR-0006: перейти к персональной мастерской и документальному портфолио V4

## Статус

Предложено для owner review.

## Контекст

ADR-0005 выбрал направление «интеллектуальный редакционный журнал + инженерная
мастерская». Итерации V2 и V3 доказали техническую применимость редакционной
системы, но проявили продуктовые риски:

- одинаковые крупные hero на разных страницах;
- гигантская serif-типографика важнее содержания;
- пустые контрастные панели создают ощущение незаполненного макета;
- AI-визуализированные портреты ослабляют доверие к персональному сайту;
- абстрактный язык вытесняет проекты, биографию и рабочие артефакты.

## Решение

Развивать V4 как «современную персональную мастерскую + документальное
портфолио».

Сохраняются:

- тёплая светлая основа;
- редакционная дисциплина;
- инженерная доказательность;
- доступность;
- минимум декоративного движения.

Изменяются:

- человек и реальные проекты становятся первичны;
- AI-лицо исключается из главного образа;
- типографическая шкала становится компактнее;
- страницы получают разные шаблоны по задаче;
- пустые плоскости заменяются артефактами;
- яркий cobalt используется только локально;
- основная навигация сокращается и получает раздел «Практика».

## Последствия

Положительные:

- сайт точнее представляет Александра;
- проекты и биография становятся доказательством;
- страницы легче отличать друг от друга;
- мобильная версия становится короче;
- контент нельзя подменить декоративной композицией.

Отрицательные:

- нужны утверждённые настоящие фотографии;
- требуется фактчекинг приватного контентного пакета;
- V2/V3 нельзя merge без переоценки;
- реализация потребует нескольких зависимых Issues.

## Совместимость

ADR-0005 остаётся историческим решением foundation. В части актуального
визуального направления, основной навигации и медиаполитики ADR-0006 имеет
приоритет после принятия владельцем.

## Проверка

Решение принимается до реализации пользовательских страниц. Визуальная
реализация отдельно проверяется на главной, биографии, каталоге, проекте и
статье.
