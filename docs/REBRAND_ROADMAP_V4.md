# Дорожная карта ребрендинга V4

## Модель выполнения

Каждый этап — отдельная Issue, ветка и Draft PR. Следующий этап начинается
только после owner review и merge обязательной зависимости.

## Этап 1. BRAND-RESET-001

Результат:

- бренд-платформа;
- архитектура сайта;
- визуальный контракт;
- ADR;
- программа реализации.

Код пользовательских страниц не изменяется.

## Этап 2. CONTENT-EXPORT-001

Результат:

- утверждённая биография;
- проверенные контакты;
- семь проектов;
- три кейса;
- стартовый журнал;
- реестр фактов и медиа.

Материалы экспортируются из приватного пакета только со статусом
`ready_for_public_export`.

## Этап 3. DESIGN-V4-001

Результат:

- токены;
- типографика;
- сетка;
- header и footer;
- базовые компоненты;
- шаблоны identity, project, case, article, practice и contact.

Контроль выполняется на тестовом контенте без подмены будущих страниц.

## Этап 4. SITE-HOME-V4-001

Результат:

- новая короткая главная;
- настоящий портрет;
- текущая работа;
- три проекта;
- маршруты практики;
- кейс;
- материалы;
- рабочий CTA.

## Этап 5. SITE-IDENTITY-V4-001

Результат:

- «Обо мне»;
- хронология;
- «Сейчас»;
- факты;
- пресс-пакет.

## Этап 6. SITE-PROJECTS-V4-001

Результат:

- каталог;
- семь проектных страниц;
- три доказательных кейса;
- статусы, источники и реальные артефакты.

## Этап 7. SITE-PRACTICE-V4-001

Результат:

- маршрутизатор «Практика»;
- страница бизнеса;
- страница образования;
- релевантные доказательства и CTA.

## Этап 8. SITE-JOURNAL-V4-001

Результат:

- истории;
- статьи;
- мысли;
- новости;
- видео;
- связи с проектами и темами.

## Этап 9. SITE-CONTACT-V4-001

Результат:

- проверенные контакты;
- назначение каналов;
- подготовка обращения;
- операционный процесс входящих;
- политика конфиденциальности.

## Этап 10. SITE-LAUNCH-V4-001

Результат:

- SEO и structured data;
- social cards;
- аналитика без персональных данных;
- accessibility и performance audit;
- проверка ссылок;
- домен, HTTPS и production release.

## Общие gates

Для каждого интерфейсного этапа:

```text
npm ci
npm run quality
npm run design:check
npm audit --audit-level=high
git diff --check
```

Дополнительно:

- 320, 390, 768, 1024 и 1440 px;
- keyboard;
- no-JS;
- reduced motion;
- 200% zoom и text size;
- Axe serious/critical = 0;
- broken images и links = 0;
- screenshot artifact;
- factual PR report.

## Запреты

- не выполнять автоматический merge;
- не смешивать этапы в одном PR;
- не переносить приватный vault целиком;
- не публиковать `owner_review` и `fact_check`;
- не выдавать code complete за deployed;
- не начинать следующий этап до принятия зависимости.
