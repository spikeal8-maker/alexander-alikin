# Требования к публичным медиа V4

В CONTENT-EXPORT-001 медиа не экспортировались: исходный пакет содержит только
бриф и карту желаемых материалов, но не утверждённый инвентарь файлов и прав.

## Обязательная запись на каждый файл

- стабильный media id и исходный filename;
- автор или правообладатель;
- источник получения;
- лицензия или явное разрешение;
- люди в кадре и статус их согласия;
- отдельная отметка о несовершеннолетних;
- допустимые страницы и контексты;
- дата проверки и дата следующего review;
- безопасный alt-текст и подпись;
- технический производный файл без лишних EXIF.

## Gate

`mediaRightsStatus: approved` обязателен до копирования файла в `public/` или
создания публичной media entry. `pending`, неизвестный автор, отсутствие
model release или неоднозначность по несовершеннолетним означают `blocked`.

Реальный утверждённый портрет используется для идентичности. Генерация нового
лица, изменение внешности, случайный стоковый портрет и искусственная
«успешная» обстановка запрещены.

Скриншоты продуктов допускаются только после проверки отсутствия персональных,
клиентских и секретных данных и подтверждения права публичной демонстрации.
